# 石門國小 PaGamO 素養教材班級授權填報

桃園市龍潭區石門國民小學校內使用的 PaGamO 素養教材班級授權填報工具。

🌐 線上網址：https://cagoooo.github.io/PaGamO/

## 功能

- 老師填報 3–6 年級班級、人數、申請老師與科目需求
- 每班最多申請 2 科
- 學校名稱與代碼固定為桃園市龍潭區石門國民小學、034725
- 後台彙整資料並套用教育局 Excel 清冊模板輸出
- 內建 favicon、PWA manifest 與 Facebook / LINE 分享預覽圖
